# Module Documentation

The twelve module identifiers currently present in the PCVR configuration are:
- `chat`
- `wordFilter`
- `fontFilter`
- `antiSpam`
- `chatbot`
- `chatEmoteRain`
- `soundAlerts`
- `textToSpeech`
- `automaticTranslation`
- `chatIntegrations`
- `chatRequest`
- `viewerCount`

These are configuration identifiers only. Runtime handlers are not yet released. Module behavior, settings schemas, dependencies, event support, and tests will be documented as each module is implemented.
