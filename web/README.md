# RiftPulse Website

The React/TypeScript/Vite client is in `client/` and targets Cloudflare Pages. It provides the public landing page, Clerk sign-in/sign-up routes, and a protected account dashboard. It intentionally does not expose per-module enable/disable controls; those belong in the in-game Settings tab.

See `client/README.md` and `../docs/CLERK_SETUP_GUIDE.md`. No Pages project or deployment has been created.
